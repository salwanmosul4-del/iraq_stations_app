# محطات العراق — تطبيق مجتمعي لحالة محطات الوقود

يعرض محطات الوقود في محافظات العراق مرتبة حسب الأقرب، مع حالة كل محطة (مفتوحة / مغلقة)، وعدد السيارات في الطابور وتقدير الانتظار،
وأنواع الوقود المتوفرة (عادي / محسّن / سوبر). يحدّث المستخدمون الحالة ببلاغاتهم.

## الشاشات والميزات
- **المحطات:** اختيار المحافظة (أو كل العراق) • زر **الخريطة** • بحث بالاسم أو الحي • فرز (الأقرب / أقصر طابور / آخر تحديث) • فلتر نوع الوقود و"مفتوحة" • إضافة محطة جديدة.
- **الخريطة:** علامات ملوّنة بحسب الحالة (أخضر مفتوحة / أحمر مغلقة / رمادي غير مؤكدة) • اضغط علامة لفتح تفاصيل المحطة وإرسال بلاغ • زر "موقعي".
  تُرسم المحطات الظاهرة في الشاشة فقط (حتى 300) للحفاظ على السلاسة؛ قرّب الخريطة لرؤية المزيد.
- **تفاصيل المحطة:** إرسال بلاغ (مفتوحة/مغلقة، عدد السيارات، الوقود المتوفر) • الاتجاهات عبر خرائط Google • مفضلة.
- **المفضلة:** محطاتك المحفوظة (على الجهاز).
- **الإعدادات:** شرح طريقة عمل الحالة ومصدر البيانات.

أول تشغيل: يقترح التطبيق أقرب محافظة لموقعك (تقريبياً حسب مركز المحافظة، وقد يخطئ قرب الحدود)، ويمكن تغييرها في أي وقت.

## قواعد الحالة (كلها في `lib/config.dart`)
- الحالة المعروضة = آخر بلاغ؛ بعد 3 ساعات دون بلاغ تظهر "غير مؤكدة" (`kStaleAfter`).
- عدد السيارات يُعرض فقط لبلاغ أحدث من 90 دقيقة (`kQueueFreshFor`).
- تقدير الانتظار = عدد السيارات × 1.0 إلى 1.8 دقيقة (`kWaitMinutesPerCarLow/High`) — أرقام تقديرية عدّلها بحسب الواقع.
- لا يُقبل بلاغ إلا ممن هو على بعد 1.5 كم أو أقل من المحطة (`kMaxReportDistanceMeters`)، وبلاغ واحد كل 10 دقائق لكل محطة (`kReportCooldown`).
- لا حسابات: دخول مجهول عبر Firebase.

## الإعداد (مرة واحدة)

### 1) Firebase
1. أنشئ مشروعاً في https://console.firebase.google.com
2. أضف تطبيق Android بمعرّف الحزمة `com.mosul_gas` (أو معرّف تطبيقك المنشور إن كان مختلفاً، وغيّره في `android/app/build.gradle.kts` أيضاً).
3. نزّل `google-services.json` وضعه في `android/app/google-services.json`.
4. Authentication ← Sign-in method ← فعّل **Anonymous**.
5. Firestore Database ← أنشئ قاعدة بيانات ← تبويب Rules ← الصق محتوى `firebase/firestore.rules` ← Publish.

### 2) المحطات
التطبيق يبدأ فارغاً. لملئه بمحطات العراق من OpenStreetMap:
```
pip install -r tools/requirements.txt
python tools/import_osm_stations.py --governorates all --dry-run          # معاينة
python tools/import_osm_stations.py --governorates all --service-account serviceAccount.json
# أو محافظات محددة فقط: --governorates IQ-NI,IQ-BG
```
(مفتاح حساب الخدمة: Firebase Console ← Project settings ← Service accounts. لا ترفعه إلى GitHub.)
بيانات OSM ناقصة أحياناً، فراجع الأسماء والمواقع بعد الاستيراد. ويمكن للمستخدمين إضافة محطات من داخل التطبيق.

**عن التكلفة:** كل فتح للتطبيق يقرأ كل محطات المحافظة المختارة من Firestore (الخطة المجانية 50 ألف قراءة يومياً).
لذلك يحمّل التطبيق محافظة واحدة افتراضياً. خيار "كل العراق" يقرأ كل المحطات (آلاف القراءات لكل فتح) فاستخدامه الكثيف قد يتجاوز الخطة المجانية.

**عن الخريطة:** تستخدم بلاطات OpenStreetMap العامة (`kTileUrl` في `lib/config.dart`) بلا مفتاح، وهذا مناسب للتجربة والاستخدام الخفيف فقط،
فسياسة OSM تمنع الاستخدام الكثيف. قبل النشر الواسع استبدل الرابط بمزوّد خرائط بمفتاحك (MapTiler / Stadia / Thunderforest ...).

### 3) بناء APK
**على جهازك** (يلزم Flutter و Android SDK):
```
flutter pub get
flutter build apk --release
```
الملف: `build/app/outputs/flutter-apk/app-release.apk`

**أو عبر GitHub Actions:** ارفع المشروع إلى مستودع، ثم Actions ← Build Android ← Run workflow،
ونزّل `app-release.apk` و `app-release.aab` من Artifacts.
(يمكنك وضع محتوى `google-services.json` في Secret باسم `GOOGLE_SERVICES_JSON` بدل رفعه.)

### 4) النشر / تحديث تطبيق موجود على Google Play
- Google Play يطلب **AAB** (`app-release.aab`) لا APK.
- لتحديث تطبيق منشور يجب: نفس معرّف الحزمة، نفس مفتاح التوقيع (upload key)، ورقم `versionCode` أكبر (الرقم بعد `+` في `pubspec.yaml`).
- Google Play يطلب **رابط سياسة خصوصية** لأن التطبيق يستخدم الموقع والإعلانات، ونموذج "أمان البيانات" (Data safety) يجب أن يذكر الموقع ومعرّف الإعلانات.
- للتوقيع بمفتاحك: Secrets باسم `KEYSTORE_BASE64` و `KEYSTORE_PASSWORD` و `KEY_PASSWORD` و `KEY_ALIAS`
  (أو `android/key.properties` محلياً). بدونها يُوقَّع البناء بمفتاح debug ولن يقبله Google Play.

## لم يُنجز بعد
- أيقونة التطبيق ما زالت أيقونة Flutter الافتراضية (`android/app/src/main/res/mipmap-*`).
- الخريطة لا تجمّع العلامات (clustering)؛ تُعرض أقرب 300 محطة للشاشة الحالية.
